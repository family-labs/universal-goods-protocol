# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately, using GitHub's private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**.

Do not open a public issue, pull request or discussion for a security problem.

Include what you found, where (contract, function or file), how to reproduce it, and the chain and address if it concerns a deployed contract. We will acknowledge your report and keep you updated while we investigate.

## Scope

The Solidity contracts in `contracts/` (including the deployments listed in the README) and the TypeScript packages in `packages/`. Vendored third-party code under `contracts/lib/` should be reported to its upstream project as well.
